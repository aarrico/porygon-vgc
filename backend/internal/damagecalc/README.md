# damagecalc

CAP-3 — damage calculation for a move used by an attacker against a defender under given field conditions.

Depends on `pokedex`. Owns and exports `FieldConditions` and type-effectiveness data — `battlesim` imports these directly rather than redefining them (AD-2). Governed by AD-1, AD-2, AD-6, AD-13 — see [ARCHITECTURE-SPINE.md](../../../_bmad-output/planning-artifacts/architecture/architecture-porygon-vgc-2026-08-19/ARCHITECTURE-SPINE.md).
