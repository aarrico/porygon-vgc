# Project Intent & Vision: porygon-vgc

## 1. Core Purpose & Target

- **What it is:** A domain-specific coaching and team-building tool for Pokemon VGC built for personal utility and portfolio demonstration.
- **Primary Problem Solved:** Inverts traditional calculator workflows by solving constraint satisfaction problems directly rather than requiring manual trial-and-error spread testing. Long term, it will use ML/AI to
analyze past tournament and battle data to suggest teams for current meta.
- **Portfolio Objectives:** Demonstrate production-grade proficiency in Go and specific target technologies missing from resume.
- **Target Environment:** Local environment initially, expanding to local containerized orchestration.
